The CLI parses arguments, resolves configuration and providers, creates a session, streams model events, dispatches tools, and renders the resulting entries.

## How do I trace a behavior?

Start at `packages/coding-agent/src/cli.ts`, follow the session factory and event handlers, then inspect the persisted JSONL rather than relying only on terminal rendering. Provider and tool tests should assert the event sequence that caused the visible result.

## Where does compaction act?

Compaction transforms older conversation context before the next model turn; it does not rewrite the original session evidence. Test both the summary and subsequent message construction.
