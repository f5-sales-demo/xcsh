The resource commands separate local validation, live comparison, mutation, retrieval, and cleanup. Keep those stages separate so a credentialed command is deliberate.

## Which resource task do I need?

- [Choose context and namespace](/xcsh/en/f5-distributed-cloud/contexts-namespaces/) before a live request.
- [Find a kind in the catalog](/xcsh/en/f5-distributed-cloud/api-catalog/) and build a [manifest](/xcsh/en/f5-distributed-cloud/manifest-fundamentals/).
- [Validate and diff](/xcsh/en/f5-distributed-cloud/validate-diff/) before [create, apply, or update](/xcsh/en/f5-distributed-cloud/create-apply-update/).
- [Get, export, or delete](/xcsh/en/f5-distributed-cloud/get-export-delete/) existing resources.
- Use [console automation](/xcsh/en/integrations-deployment/chrome/) only for a supported interface task that has no resource-command equivalent.
