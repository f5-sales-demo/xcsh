The resource commands separate local validation, live comparison, mutation, retrieval, and cleanup. Keep those stages separate so a credentialed command is deliberate.

## Which resource task do I need?

- [Choose context and namespace](./contexts-namespaces/) before a live request.
- [Find a kind in the catalog](./api-catalog/) and build a [manifest](./manifest-fundamentals/).
- [Validate and diff](./validate-diff/) before [create, apply, or update](./create-apply-update/).
- [Get, export, or delete](./get-export-delete/) existing resources.
- Use [console automation](./console-automation/) only for a supported interface task that has no resource-command equivalent.
