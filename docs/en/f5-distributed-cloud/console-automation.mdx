Console automation drives a browser session through xcsh. Use deterministic resource commands when they cover the task; browser state and page structure make console workflows more fragile.

## How do I inspect the Chrome session?

Run `xcsh chrome --help`, then use the supported session inspection or arrangement action shown by the installed version. Keep the browser profile dedicated to authorized lab work.

## What counts as evidence?

Record the page URL, visible control or result, browser action, and cleanup state without capturing tokens or tenant identifiers. If the interface cannot be exercised, document only source-verified capability and omit procedural success claims.
