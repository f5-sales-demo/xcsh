Extend xcsh only when a built-in command or tool cannot express the task.

## Which extension mechanism fits?

- [Headless modes](./headless-protocols/) drive xcsh from a script over a process boundary.
- [Software development kit (SDK) automation](./sdk/) embeds sessions in a host application.
- [Extensions and custom tools](./extensions-custom-tools/) run TypeScript hooks or tools.
- [Hooks and rules](./hooks-rules/) choose between lifecycle code and declarative guidance.
- [Skills](./skills/) add discoverable instructions.
- [Plugins and marketplaces](./plugins-marketplaces/) package installable capabilities.
- [Model Context Protocol (MCP) quickstart](./mcp-quickstart/) connects one out-of-process server.
- [MCP configuration](./mcp-configuration/) declares transports, variables, and disabled servers.
- [MCP runtime and authoring](./mcp-runtime-authoring/) traces connection lifecycle and server contracts.
