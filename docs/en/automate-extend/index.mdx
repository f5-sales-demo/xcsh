Extend xcsh only when a built-in command or tool cannot express the task.

## Which extension mechanism fits?

- [Headless modes](/xcsh/en/automate-extend/headless-protocols/) drive xcsh from a script over a process boundary.
- [Software development kit (SDK) automation](/xcsh/en/automate-extend/sdk/) embeds sessions in a host application.
- [Extensions and custom tools](/xcsh/en/automate-extend/extensions-custom-tools/) run TypeScript hooks or tools.
- [Hooks and rules](/xcsh/en/automate-extend/hooks-rules/) choose between lifecycle code and declarative guidance.
- [Skills](/xcsh/en/automate-extend/skills/) add discoverable instructions.
- [Plugins and marketplaces](/xcsh/en/automate-extend/plugins-marketplaces/) package installable capabilities.
