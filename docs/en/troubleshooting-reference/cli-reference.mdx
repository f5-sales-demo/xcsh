The installed help is the command authority for its release.

## Which top-level commands exist?

| Area | Commands |
| --- | --- |
| Resources | `validate`, `diff`, `create`, `apply`, `update`, `get`, `export`, `delete` |
| Runtime | `config`, `setup`, `sandbox`, `stats`, `search`, `shell` |
| Extensibility | `agents`, `plugin`, `worker`, `manager` |
| Interfaces | `chrome`, `office`, `herdr` |
| Maintenance | `self-update`, `update --check` |

## How do I script a command safely?

Run `xcsh <command> --help` against the pinned executable, prefer long flags, and request `--result-file` or JSON where supported. On `update`, `-f` means a resource manifest; executable force-update uses `--force`.
