The Chrome integration connects xcsh to a browser session for supported console automation. The installed `xcsh chrome --help` output is the command authority.

## What is the safe operating boundary?

Use a dedicated profile and an authorized target. Confirm the visible account, URL, and object before an action that changes state. Prefer deterministic F5 Distributed Cloud resource commands whenever they cover the same operation.

## What is verified here?

The repository exposes Chrome session inspection and arrangement through the `chrome` command. Interface-specific procedures require a captured browser transcript; this page does not claim an untested click path.
