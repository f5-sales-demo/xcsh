Choose an interface by interaction model, not by appearance.

## Which interface fits?

- [Terminal CLI](./terminal-cli/) for interactive or one-shot work.
- [Headless protocols](./headless/) for process integration.
- [Containers](./containers/) for an isolated packaged runtime.
- [VS Code](./vscode/), [Chrome](./chrome/), or [Office](./office/) only when that companion surface is installed and the task needs it.
