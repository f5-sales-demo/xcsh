The Office pane packages an xcsh sidebar for supported Excel, Word, and PowerPoint hosts. `xcsh office --help` describes the installed serve, print, and sideload actions.

## What must be running?

The pane build and its local bridge/server must match the xcsh version used for the session. One active sidebar is bound to one server session at a time.

## What is not asserted here?

Host-specific menu and sideload steps vary by Office platform. Without a recorded host transcript, this page describes the source-verified boundary only and does not promise a particular ribbon path.
