Configuration controls provider routing, settings precedence, filesystem access, and credential handling.

## What should I configure first?

1. Inspect [settings precedence and file locations](./settings-files/).
2. Look up any [environment variable](./environment-reference/) the deployment sets.
3. Choose a [provider and model route](./providers-routing/).
4. Apply [secret handling and the filesystem boundary](./secrets-obfuscation/).
5. Set the [sandbox boundaries](./sandbox-boundaries/) that enforce those decisions.

Start with defaults; add project configuration only when collaborators need the same behavior.
