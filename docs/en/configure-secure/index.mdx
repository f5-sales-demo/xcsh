Configuration controls provider routing, settings precedence, filesystem access, and credential handling.

## What should I configure first?

1. Choose a [provider and model route](./providers-routing/).
2. Inspect [settings and file locations](./settings-files/).
3. Apply [secret and filesystem boundaries](./secrets-obfuscation/).

Start with defaults; add project configuration only when collaborators need the same behavior.
