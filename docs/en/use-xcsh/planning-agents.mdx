New sessions start in Default mode and respond or act when your intent is clear. The agent asks for clarification only when a missing decision materially affects the result. It can choose progress tracking for substantial work or when you request a TODO list; an unfinished checklist alone does not restart a paused conversation.

Planning mode separates investigation and decisions from implementation. Use it when a task has multiple files, external side effects, or unresolved product choices.

Select Plan Mode explicitly with `/plan` or the collaboration controls. A resumed session restores its saved mode. While Plan Mode is active, discuss and refine the plan in the conversation; `todo_write` execution checklists become available again when you switch to Default mode.

## What belongs in a decision-complete plan?

State the objective, scope boundaries, exact files or systems, ordered changes, validation, rollback or cleanup, and decisions that still require a person. A list of vague intentions is not executable.

## When should I use a specialized agent?

Use a bounded agent when its definition matches one independent subtask. Export editable bundled definitions with `xcsh agents unpack --project`, review `.xcsh/agents/`, and inspect the agent result before accepting it. The parent session remains responsible for integration and validation.

A decision-complete plan names files or surfaces, ordered changes, invariants, verification, and any
irreversible boundary. Use a specialized agent only when its task is independently checkable and its
result can be reconciled into the parent session. Agent delegation does not expand credentials or
approval. Before execution, resolve conflicting edits and confirm that every delegated result came
from the same source revision.
