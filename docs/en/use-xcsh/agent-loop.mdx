A user message enters the selected model. The model may request a tool; xcsh executes the allowed tool, appends its result, and continues until the model produces a final response or the run stops.

## Where is the durable record?

Session JSON Lines (JSONL) stores messages and tool events. The terminal rendering is a view of that state, not the canonical record. Export or inspect the session when an exact sequence matters.

## Where are side effects introduced?

Model text alone does not change files or external systems. Tools such as shell, edit, browser, and task agents can. Restrict a run with `--tools`, `--no-tools`, `--no-mcp`, or `--no-extensions` when the task needs a smaller boundary.
