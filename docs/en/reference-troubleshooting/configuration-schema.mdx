The schema groups settings for appearance, models, interaction, context, editing, tools, tasks, providers, and sandboxing. It evolves with the executable.

## How do I inspect the effective schema-backed values?

```sh
xcsh config list --json
xcsh config get <key>
```

Use `xcsh config set <key> <value>` only for a key present in the installed schema. Reset one key with `xcsh config reset <key>` rather than copying defaults from another release.

## Which source defines a setting?

The settings schema and its tests in the matching source release define type, default, and validation. Effective output defines the value after precedence is applied.
