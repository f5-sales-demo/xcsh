Slash commands are interactive TUI controls, not shell subcommands. Type `/` to view the registry active in the current session.

## How do I find a command or keybinding?

Run `/help` for categorized commands and `/hotkeys` for the resolved terminal key map. Use `/model`, `/context status`, and `/mcp status` to inspect those subsystems.

## Why can the list differ?

The installed release, current mode, and loaded extensions can change the registry. Runtime completion is therefore canonical; this page intentionally does not freeze a complete list or key table.
