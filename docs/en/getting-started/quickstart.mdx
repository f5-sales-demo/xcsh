This quickstart proves the executable, provider selection, and one non-interactive model turn without changing repository or cloud state.

## How do I run a bounded first prompt?

```sh
xcsh --version
xcsh --list-models ''
xcsh --no-session --no-tools -p "Reply with only: xcsh is ready"
```

Select a provider-qualified model with `--model` if more than one provider is configured. `--no-session` prevents persistence and `--no-tools` prevents tool side effects.

## What should I inspect if the prompt fails?

Confirm the provider credential is available to the process without printing it, then run `xcsh --list-models <provider>`. A missing model points to provider configuration; a missing executable points back to [installation](../installation/).
