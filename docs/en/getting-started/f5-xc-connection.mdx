An F5 Distributed Cloud context binds an API endpoint, credential, and optional default namespace. Treat the context file as a secret.

## How do I select the intended context?

Start the TUI with `xcsh --context <name>`, then run `/context status`. Confirm the displayed context name and namespace before any live command. Use `-n <namespace>` on a resource command when the manifest must override the context default.

## What is safe to test first?

Run `xcsh validate -f <manifest>` before using network access. Then run `xcsh diff -f <manifest> --result-file diff.json`; inspect the report before choosing a mutation command.
