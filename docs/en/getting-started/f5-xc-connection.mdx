An F5 Distributed Cloud context binds an application programming interface (API) endpoint, credential, and optional default namespace. Treat the context file as a secret.

## How do I select the intended context?

Start the terminal user interface (TUI) with `xcsh --context <NAME>`, then run `/context status`. Confirm the displayed context name and namespace before any live command. Use `-n <NAMESPACE>` on a resource command when the manifest must override the context default.

## What is safe to test first?

Run `xcsh validate -f <MANIFEST>` before using network access. Then run `xcsh diff -f <MANIFEST> --result-file diff.json`; inspect the report before choosing a mutation command.
