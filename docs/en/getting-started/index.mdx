Use this section to reach the first useful command without configuring every optional integration.

## What do I need before I begin?

You need a supported xcsh build and one model provider. F5 Distributed Cloud credentials are needed only for live resource commands; local manifest validation works without them.

## Which path matches my goal?

1. [Install, update, or remove xcsh](./installation/).
2. [Authenticate a model](./model-authentication/), which the quickstart requires.
3. Run the [general quickstart](./quickstart/).
4. Connect an [F5 Distributed Cloud context](./f5-xc-connection/) when you intend to reach a tenant.
5. Complete [your first manifest lifecycle](./first-manifest/) against a lab namespace you are authorized to change.
