Use this section to reach the first useful command without configuring every optional integration.

## What do I need before I begin?

You need a supported xcsh build and one model provider. F5 Distributed Cloud credentials are needed only for live resource commands; local manifest validation works without them.

## Which path matches my goal?

1. [Install, update, or remove xcsh](/xcsh/en/#install-xcsh).
2. [Authenticate a model](/xcsh/en/getting-started/model-authentication/), which the quickstart requires.
3. Run the [general quickstart](/xcsh/en/#quickstart).
4. Connect an [F5 Distributed Cloud context](/xcsh/en/f5-distributed-cloud/contexts-namespaces/) when you intend to reach a tenant.
5. Complete [your first manifest lifecycle](/xcsh/en/getting-started/first-manifest/) against a lab namespace you are authorized to change.
