Choose an integration by host, authority, and lifecycle boundary.

## Which integration fits?

- [Containers](/xcsh/en/integrations-deployment/containers/) for Mac or Linux Podman, Docker, persistent state, and explicit model and service authentication.
- [VS Code](/xcsh/en/integrations-deployment/vscode/), [Chrome](/xcsh/en/integrations-deployment/chrome/), [Office](/xcsh/en/integrations-deployment/office/), or [Herdr](/xcsh/en/integrations-deployment/herdr/) only when that companion surface is installed and the task needs it.
