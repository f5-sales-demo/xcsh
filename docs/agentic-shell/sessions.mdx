Continue, locate, fork, or export persisted conversations.

## Prerequisites

- A current xcsh release and a shell in the intended working directory.
- Authorization for any account, tenant, repository, or file the procedure touches.
- A backup or dry run before an operation that changes or deletes state.

## Procedure

<Steps>

1. Continue the latest directory session with `xcsh --continue`.
2. Choose a stored session with `xcsh --resume` or provide an ID prefix or path.
3. Fork without changing the original with `xcsh --fork <session>`.
4. Export a session file to HTML with `xcsh --export <session.jsonl>`.

</Steps>

## Expected result

The command or interface reports completion in the selected scope. For automation, prefer its structured result instead of parsing decorated terminal output.

## Troubleshooting

Confirm the installed version and resolved configuration first. Retry with optional plugins, MCP servers, or extensions disabled when they could affect the path. Never print tokens while collecting diagnostics.
