# Node F5 core source and prototype receipt

This implements the shared-core extraction work for xcsh #5072, linked to
vscode-xcsh #1708. Production editor delivery remains gated by specialist
routing and the remaining editor integration/release acceptance.

## Shared implementation

`packages/f5-core` bundles the CLI's pinned specification 12.5.1 and the actual
resource implementation into standalone Node ESM/CommonJS artifacts. The CLI
and core use the same catalog-aware kind resolver. Immutable selection/schema
helpers and manifest comparison now live in resource-management and remain
shared with the CLI's existing API/replacement tools. The CLI resource transport
uses the new single-attempt implementation rather than retrying uncertain writes.

The bundled specification projection is 17,040,213 JSON bytes and 1,471,243 gzip
bytes, with SHA-256
`3f62329f0e12ecae1789d5579ba513c31589e3ac44e0bcf74d8a14e9720692e3`.
Its receipt binds the upstream release/commit, immutable asset hashes, generated
CLI input hashes and projection hash. Discovery matches the 94 CLI-indexed CRUD
resource kinds; coverage of every API catalog operation is not claimed.

Every core operation uses an opaque workspace/context/conversation binding.
Plans bind the original request, exact context revision, credential fingerprint,
specification and observed resource state. Host approval must return that plan's
hash. Plans are single-use; stale bindings/resources, canceled/mismatched
approvals, credential rotation and immutable selection changes block dispatch.
The context is rechecked synchronously immediately before transport. Successful
mutations require independent matching readback with nonempty identity/version;
uncertain outcomes and post-write persistence failure require reconciliation.

Secret references are scoped to the originating binding. They restore privately
before validation/planning and do not corrupt protocol IDs or hashes. The core
does not read native credentials, choose models, activate contexts, or change
profile persistence/environment behavior; those remain host-owned adapters.

The CLI exposes credential-free capability/discovery commands. Negotiation
checks protocol/specification and returns only the understood enhancement
intersection, retaining all bundled capabilities when optional CLI use fails.
CLI mutation delegation is not advertised. The normal publication wave now
includes the core after resource-management and before the CLI.
