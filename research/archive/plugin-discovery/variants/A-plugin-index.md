# Installed Plugins

Installed plugins expose domain capabilities, schemas, and executable helpers on
demand. When a task falls in a plugin's domain, consult the plugin — read
`xcsh://plugin/<name>` for its summary and follow its pointers — rather than
answering from memory or from values embedded in a data file.

- **meddpicc** — MEDDPICC sales qualification and deal-execution framework:
  evidence-based deal management, stakeholder mapping, mutual action plans, and
  forecast integrity for complex enterprise B2B sales. Deal files are scored and
  sequenced by its engine, not by hand. → `xcsh://plugin/meddpicc`
