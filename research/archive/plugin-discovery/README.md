# Plugin Discovery Experiment

Status: completed and archived.

This directory preserves the report, acceptance criteria, phrase set, and variants from the plugin-discovery experiment as of `7d74c63f5` (2026-07-31). Nothing here is run by CI or released in an npm package.

Raw fixtures, execution transcripts, and their obsolete runner scripts were intentionally removed. The captures included workstation paths and live environment context that are not appropriate for a source archive.

The experiment should only be revived as a new maintained benchmark with an owner, synthetic fixtures, and explicit release-validation coverage.
