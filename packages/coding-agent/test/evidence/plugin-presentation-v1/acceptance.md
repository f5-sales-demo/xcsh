# Plugin presentation acceptance

Public captures use synthetic data. Live Salesforce ANSI captures remain in private task storage.

The registered-tool regression matrix exercises xcsh-dark and xcsh-light, Unicode, ASCII and Nerd
symbols, and widths of 40, 76, 120 and 153 cells. It verifies complete expanded content, zero/false/null,
empty results, Unicode, multiline cells, large tables, partial results, cancellation and renderer
failures. `captures.json` contains 48 actual component renders and hashes of their source files.

The installed baseline is xcsh 23.3.3 with Salesforce 2.0.5. A task-owned Herdr pane reproduced the
hidden zero aggregate and clipped error. The Bun candidate, using the same LiteLLM default model,
authenticated Salesforce org and read-only prompts, visibly displays `total = 0` and complete
invalid-field guidance. Org and describe results wrap and show remaining-row counts. The packaged
Mac candidate passed the release builder's CLI, native and embedded-bundle smoke checks.

The coordinated marketplace gate loads all 23 plugins through installed-plugin discovery, uses
synthetic command fixtures, and verifies every marketplace tool descriptor and themed message
surface. No infrastructure is provisioned by these fixtures.

Lifecycle reviews continue to use the existing review, cancellation and authentication controls.
Setup command tests round-trip exact empty, multiline and shell-sensitive arguments, and retain
dependencies, timeouts and verification commands.

This receipt covers the shared rendering primitives. Released and installed acceptance is recorded
in the linked delivery issues; this source receipt alone does not assert that release gate.
